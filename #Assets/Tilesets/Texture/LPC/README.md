# LPC ruin and dead-tree sprites

`Ruins.png` is an atlas cut from two OpenGameArt packs (regions are listed in `#Scripts/World/Art.cs`):

- "[LPC] Jungle Ruins" by bluecarrot16, commissioned by Pierre Vigier (pvigier). OGA-BY 3.0+ / CC-BY 3.0+ / GPL 2.0+.
  https://opengameart.org/content/lpc-jungle-ruins (credits: `CREDITS-jungle-ruins.txt`)
- "[LPC] Trees" (`trees-dead.png`) by bluecarrot16 and the authors listed in `CREDITS-trees.txt`. CC-BY-SA 3.0.
  https://opengameart.org/content/lpc-trees

The atlas is a derivative of the CC-BY-SA tree sheet, so the atlas itself stays under CC-BY-SA 3.0. All authors in both credit files must be credited in the shipped game.
